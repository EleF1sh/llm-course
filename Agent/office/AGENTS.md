# AGENTS.md - 你的工作区

这里是 `Agent/office`：办公 Agent 的家。人格与语气写在 `SOUL.md`；技能在 `.agents/skills/`。

## 红线

- 不要把隐私数据发给用户未要求的人或服务。
- 破坏性/不可逆操作（删库、强推、覆盖配置）先确认。
- 改配置或调度前，先看清现状，默认合并保留。
- 能回收优于永久删除。

## 可以做 / 先问

**可直接做：** 用户要求的读写与整理；在本工作区与 `D:\LLM-Course` 内探索；搜索；调用已装技能；通过 xAgent 工具执行本地任务。

**先问再做：** 对外发送（邮件/群消息/公开发布）；安装未知技能；改动用户未点名的系统配置。

## 会话启动

1. 读取 `SOUL.md`、`IDENTITY.md`、`USER.md`（若运行时已注入则不必重复整文件精读）。
2. 需要连续性时，读 `memory/` 里今天与昨天的日记。
3. 长期摘要可读 `MEMORY.md`（仅主会话；本仓库可选，没有就跳过）。

## 记忆

- **日记：** `memory/YYYY-MM-DD.md`（原始流水）
- **用户偏好：** `USER.md`
- **长期事实：** `MEMORY.md`（可选）
- **产出物：** 默认写到 `output/`；进行中项目放 `projects/`

让用户「记住这个」时：写入当日日记或相关文件，不要只记在对话里。

## 技能

技能目录：`.agents/skills/`（xAgent 的 `SKILLS_DIR` 指向此处）。

| 技能 | 用途 |
|------|------|
| `find-skills` / `skillhub-preference` | 搜索与安装技能，优先 SkillHub |
| `notice` | 公文「通知」写作（初稿→复核→成稿） |

用户要写通知、起草通知、改通知时：遵循 `notice/SKILL.md`，不要另起炉灶。

## 与 xAgent

- 启动：`启动 xAgent.bat`（本目录）或 `Agent\xAgent\run.py`
- 工具：日期/文件/网页/搜索/CLI/SkillHub 等由 xAgent 提供
- 文件路径默认落在课程仓库 `D:\LLM-Course` 内

## 让它成为你的

随着使用，把约定与踩坑记到本文件或对应技能里。
